# VyreX

Instant replay clipping, an in-game overlay and peer-to-peer voice chat for PC gamers. Small, fast, no account needed.

## ⬇ Download

**[Download VyreX for Windows](https://github.com/mikaelperakoski-creator/VyreX/releases/latest)**: get the file named `VyreX_..._x64-setup.exe` under **Assets**.

1. Run the installer.
2. If Windows says *"Windows protected your PC"*, click **More info → Run anyway**. VyreX isn't code-signed yet.
3. Done. VyreX updates itself when a new version comes out.

## Features

- **Instant replay**: press **F8** to save the last 15s–10 min. The buffer is on your SSD, not your RAM.
- **All PC audio**: game sound, voice chat and music in every clip, plus your mic if you want.
- **Library**: all your clips in one place, grouped by day.
- **Overlay**: clip alerts and your voice channel in the corner of your screen. It switches to alerts-only automatically when an anti-cheat game (CS2, Valorant, ...) is running, and never injects into games.
- **Voice**: up to 12 people, peer-to-peer and encrypted. Same room name + password = same channel.

Windows 10/11, 64-bit.
